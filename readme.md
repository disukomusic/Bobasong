# The Bobasong
Designed by [disuko](https://disuko.gay) for the Create With Nabalis 2025 contest. 
I didn't get first place for mass production, so I decided to open source the design as a platform to allow the community to make their own bobasong, build off of it, check out how it was made, and more!

Please read the full license below. TL:DR the bobasong is fair game for all personal use. You can make your own, give them away, self-host the files, whatever you want **non-commercially.**
Commercial use for derivative works is allowed **with permission from the copyright holder (that's me!)**
